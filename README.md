# Revenue Opportunities & Pipeline Analysis Dashboard

## Project Overview

This project presents an interactive two-page Revenue Opportunities & Pipeline Analysis Dashboard developed using Microsoft Power BI.

The report focuses on analyzing revenue opportunities, regional performance, business partner contributions, opportunity segmentation, and sales pipeline progression.

It provides both a high-level overview of revenue performance and a detailed breakdown of individual business opportunities.

### Page 2 – Opportunity Detail Analysis

![Opportunity Detail Analysis](Screenshots/Page_2_Opportunity_Detail.png)

**Key Features:**
- Opportunity segmentation into Large, Medium, and Small categories

- Partner-wise revenue contribution
